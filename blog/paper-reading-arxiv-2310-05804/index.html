    0 comments
    Arxiv ID 2310.05804
    幻觉翻译 2310.05804

    语言引导的自适应超模态表示学习（EMNLP'23）

    本文提出 ALMT，以语言作为主导模态，通过三个尺度的语言特征引导自适应超模态学习（AHL），从音频和视觉中筛选补充信息，抑制与情感无关或相冲突的干扰，再使用跨模态 Transformer 进行融合。模型仅使用 MSE 训练目标，在 MOSI、MOSEI 和 CH-SIMS 上验证了该设计；其中 MOSI Acc-7 达 49.42%，CH-SIMS Acc-5 达 45.73%，展示了较好的分类性能与模型规模折中。

    学习语言引导的自适应超模态表示以实现多模态情感分析 EMNLP’23 (CCF-B)

    ALMT 代码：Haoyu-ha/ALMT

    1. 研究背景与动机#

    (1) 要解决什么问题？ 辅助模态（论文中指视觉模态与语音模态）中的信息未必都与情感有关：光照、头部姿态、录音环境、背景声等因素会改变视觉和音频特征，但不一定改变说话者的情感态度。融合网络若把它们当作预测依据，额外模态可能带来干扰。

    ALMT 的结构先验是：在使用的多模态情感数据集上，语言通常包含较强的情感线索，可以用它作为查询，决定如何从其他模态中聚合信息。这里有两类不同的问题：

    问题例子需要的能力
    与情感无关的变化灯光、背景噪声改变降低对干扰因素的依赖
    模态之间不一致文字积极但表情消极结合上下文判断冲突是否有意义

    论文将工作分成表示学习和最终融合两步：先得到与语言相关的音视频超模态的表示，再进行多模态融合与输出。

    2. 核心贡献#

    • ALMT 将语言作为跨模态信息筛选的条件，针对音频和视觉中可能存在的情感无关变化，学习更聚焦的联合表示，显式处理辅助模态中冗余和冲突信息的不利影响，从而提升情感理解性能。
    • 模态嵌入模块把较长输入约束为少量可学习 token；多层语言表示利用不同尺度的语言特征，引导视觉和音频模态形成一个补充语言模态的超模态。
    • 论文在 MOSI、MOSEI 和 CH-SIMS 上报告了具有竞争力的结果，并通过消融实验验证各模块的作用。

    3. 方法详解#

    3.1 整体架构与参数#

    ALMT 首先从输入中提取统一模态特征。然后，采用自适应超模态学习（AHL）模块，在不同尺度的语言特征引导下学习自适应的超模态表示。最后，应用跨模态融合 Transformer，以语言特征为锚点，融合超模态特征，从而获得用于 MSA 的语言引导超模态网络。

    原文在 MOSI 数据集上给出的输入长度均为 50，语言、音频、视觉输入维数分别为 768、5、20，总体上以 BERT、Librosa、OpenFace 描述三种输入来源，相关参数与变量含义如下：

    3.3 三尺度语言特征构建#

    模态嵌入之后，进一步采用自适应超模态学习（AHL）模块，以学习一种精炼的超模态表示。该表示抑制与情感无关或相冲突的信息，并能补充语言特征。

    论文将 Hl1H_l^1Hl1​ 作为低层尺度，再接两层 Transformer 得到中、高层表示，公式为：

    Hli=Eli(Hli−1;θEli),i∈{2,3}H_l^i=E_l^i(H_l^{i-1};\theta_{E_l^i}),\qquad i\in\{2,3\}Hli​=Eli​(Hli−1​;θEli​​),i∈{2,3}

    三个表示的形状都为 8×1288\times1288×128，先由 BERT 产生语言输入，模态嵌入得到 Hl1H_l^1Hl1​，再由 ALMT 自己的两层语言 Transformer 产生后两种尺度，更深层可以经过更多上下文混合，从而提供不同查询。三个尺度可以分别指导三个 AHL 层，使音视频信息的读取能够依赖不同深度的语言表示。

    3.5 多模态融合与输出#

    完成 AHL 后，模型将一个 1×1281\times1281×128 的初始 token H0H^0H0 分别拼到最终语言表示和 hyper 表示前：

    Hl=[H0;Hl3]∈R9×128,Hhyper=[H0;Hhyper3]∈R9×128H_l=[H^0;H_l^3]\in\mathbb R^{9\times128},\qquad H_{hyper}=[H^0;H_{hyper}^3]\in\mathbb R^{9\times128}Hl​=[H0;Hl3​]∈R9×128,Hhyper​=[H0;Hhyper3​]∈R9×128

    这里的 H0H^0H0 与 AHL 的 Hhyper0H_{hyper}^0Hhyper0​ 不同，前者只有 1 个 token，后者有 8 个。

    H=CrossTrans⁡(Hl,Hhyper)∈R1×128H=\operatorname{CrossTrans}(H_l,H_{hyper})\in\mathbb R^{1\times128}H=CrossTrans(Hl​,Hhyper​)∈R1×128

    多模态融合后，对跨模态融合 Transformer 的输出 HHH 应用线性回归头，得到最终的情感分数 y^\hat yy^​。沿用上文 H∈R1×128H\in\mathbb{R}^{1\times128}H∈R1×128 的行向量约定，令 w∈R128×1w\in\mathbb{R}^{128\times1}w∈R128×1，有：

    y^=Hw+b.\hat y=Hw+b.y^​=Hw+b.

    原文唯一的训练目标为均方误差：

    L=1N∑n=1N∥yn−y^n∥22\mathcal L=\frac1N\sum_{n=1}^{N}\lVert y_n-\hat y_n\rVert_2^2L=N1​n=1∑N​∥yn​−y^​n​∥22​

    得益于单一的优化目标，ALMT 无需为多个损失项额外调整权重超参数。

    4.1 实验设置#

    • 任务与输入：利用语言、视觉和声学信息预测片段的连续情感分数，再用分类指标评价情感方向与强度的识别效果。
    • 数据划分：在 MOSI、MOSEI 和 CH-SIMS 上采用论文给出的固定训练、验证、测试划分，统计如下。

    • 训练：采用 MSE 损失与 AdamW，初始学习率为 10−410^{-4}10−4，batch size 为 64，训练 200 个 epoch，使用 warm-up 和余弦退火。三个数据集均取 T=8T=8T=8、d=128d=128d=128，模态嵌入深度为 1，AHL 深度为 3；最终融合 Transformer 在 MOSI、MOSEI、CH-SIMS 上的深度分别为 2、4、4。
    • 指标：Acc-2、F1 衡量二分类，Acc-3 / Acc-5 / Acc-7 衡量不同粒度的情感分类，MAE 与 Corr 衡量连续预测误差及相关性。MAE 越小越好，其余指标越大越好。MOSI/MOSEI 表中 Acc-2、F1 的斜线左、右分别为“负面/非负面”和“去除零分后的负面/正面”两种口径；以下分类提升均以百分点表示。

    (b) AHL 是主要增益来源，模态嵌入和最终融合也有贡献。 保留三模态输入、把 AHL 换成特征拼接后，MOSI Acc-7 从 49.42% 降至 34.40%，下降 15.02 个百分点，MAE 从 0.683 升至 0.952；CH-SIMS Acc-5 下降 7.44 个百分点，MAE 从 0.404 升至 0.444。即使只保留一种辅助模态，进一步去掉 AHL 仍会降低两个数据集的分类准确率，支持语言引导的辅助信息处理具有作用。

    相比之下，去掉模态嵌入使 MOSI / CH-SIMS 分类准确率分别下降 1.46 / 2.62 个百分点，去掉最终融合 Transformer 则下降 0.73 / 1.97 个百分点。因此，主要改进来自 AHL，输入表示和最终融合共同完善预测。

    6. 局限性与启示#

    (1) 局限

    基于 Transformer 的 ALMT 模型通常具有较多参数，需要充分训练，因此对训练数据集的大小较为敏感。由于当前的情感数据集通常规模较小，ALMT 的性能可能受到限制，部分回归指标上的提升小于分类提升。

    (2) 启示

    我觉得 ALMT 最值得掌握的是其清晰的设计：围绕抑制辅助模态中无用干扰信息的目标，添加具体且精简的模块，并最终在性能与参数规模之间取得相对完善的平衡。
