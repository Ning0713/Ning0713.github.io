    通过通用多模态大模型提示改进任务特定的多模态情感分析（NeurIPS'25）

    本文提出 MMSLF，将通用多模态大模型生成的情感线索用于提示条件跨模态对齐，再通过注意力迁移与融合表示匹配指导学生模型，使其在推理时无需调用大模型或读取提示。在 SIMS 上，学生以 0.82M 核心参数取得 81.85% 的 F1，展示了性能与部署成本的折中；MOSI、MOSEI 上的回归收益则较有限，提示质量与知识迁移仍是关键。

    通过提示利用通用多模态大语言模型改进特定任务的多模态情感分析 NeurIPS’25 (CCF-A)

    MMSLF 代码：LOGO-CUHKSZ/MMSLF

    1. 研究背景与动机#

    (1) 任务目标：利用语言、视觉和声学信息预测片段的情感倾向与强度。

    一个样本包含转录文本、视频和音频，以及一个整体情感分数。语言提供“说了什么”，视觉与声学补充表情、动作和说话方式。模型需要把这些信息组合起来，得到连续预测：

    y^=f(XL,XA,XV).\hat y=f(X_L,X_A,X_V).y^​=f(XL​,XA​,XV​).

    L,A,VL,A,VL,A,V 分别表示语言、音频、视觉；XmX_mXm​ 是对应模态的输入序列。CH-SIMS 的标签范围为 [−1,1][-1,1][−1,1]，MOSI 与 MOSEI 为 [−3,3][-3,3][−3,3]。连续分数既能衡量情感强度，也能按评价规则转换为情感方向的分类结果。

    (2) 通用大模型具有丰富的语义知识，但逐样本调用的部署代价较高。

    任务特定的多模态模型主要依赖有限的情感标注学习关联，可能难以识别隐含态度，或难以判断哪些视觉、声学变化与情感有关。通用多模态大模型能够结合语境解释情感线索，例如指出某个评价词、面部动作或表情可能值得关注；但直接用它处理每个测试样本，需要承担图像输入、文本生成和外部服务调用的成本。

    MMSLF 因而把大模型的作用前移：先让大模型生成线索说明，再让教师模型学习如何利用这些线索，最后把学习结果迁移给独立运行的学生模型。核心问题是：如何把自然语言提示变成可学习的跨模态关系，并在移除提示后保留其作用？

    (3) 大模型、教师模型和学生模型承担不同职责。

    2. 核心贡献#

    • 建立通用大模型指导的特定任务模型学习框架。 利用通用 MLLM 生成情感提示，经教师模型转化为训练信号，学生部署时只需三模态输入。
    • 设计提示条件跨模态对齐。 用提示与源模态之间的匹配分数调制普通跨注意力，使语言位置可以依据提示重新分配对音视频信息的关注。
    • 联合迁移注意力和融合表示。 学生模型同时接受真实情感标签、教师模型最后一层的对齐关系与融合表示监督，分别学习预测结果、信息读取方式和整体表达。
    • 验证性能与部署成本的折中。 在 CH-SIMS、MOSI、MOSEI 上比较整体效果，并通过提示、蒸馏目标、学生容量和效率实验分析各部分的作用。

    3. 方法详解#

    3.1 整体架构与参数#

    教师与学生都经过模态嵌入、跨模态对齐、多模态融合和情感预测；教师额外接收提示，学生额外接受蒸馏监督。

    模型先把三种输入映射到统一通道维度，再分别将音频和视觉对齐到语言位置，得到 HA→LH_{A\to L}HA→L​ 与 HV→LH_{V\to L}HV→L​。两个序列随后进入融合 Transformer，由汇总表示输出一个情感分数。

    A→LA\to LA→L 表示以语言为 Query，读取音频的 Key/Value：输出位置对应语言位置，每个位置聚合一部分声音信息。V→LV\to LV→L 同理，读取视觉信息。因此，对齐是跨模态信息的加权聚合，教师模型在对齐时加入提示条件；而学生模型使用普通的跨注意力，并通过训练学习接近教师模型的关系与表示。

    3.2 模态与提示编码#

    (1) 三种输入分别进行线性嵌入。

    原文以 BERT、OpenFace、Librosa 概括语言、视觉和声学输入的处理方式。对数据集提供的模态序列，分别使用独立嵌入层：

    Sm=Em(Xm;θEm)∈RTm×d.S_m=E_m(X_m;\theta_{E_m}) \in\mathbb R^{T_m\times d}.Sm​=Em​(Xm​;θEm​​)∈RTm​×d.

    SmS_mSm​ 表示模态 mmm 的嵌入特征，m∈{L,A,V}m\in\{L,A,V\}m∈{L,A,V}，θEm\theta_{E_m}θEm​​ 表示与每个嵌入层相关联的参数。线性层把不同通道的特征映射到 64 维，保留各自的序列长度；跨模态关系由后面的对齐模块学习。

    (2) 大模型离线生成情感线索。

    默认使用的通用大模型为 GPT-4o-mini；在论文的提示来源对照中，它整体上优于 Gemini-2.0-Flash，但并非所有学生指标均领先。均匀采样三帧视频并结合转录文本，要求大模型描述表情、动作以及情感词语。例如原文提示样例会指出 “surprisingly decent cast” 表达了超出预期的正向评价，并建议关注相关表情。这些文字形成提示 XPX_PXP​，在训练前生成并缓存。

    由于 GPT-4o-mini 不能直接输入音频，附录说明可以让其根据文本推测可能的声音线索。因此，声音相关提示来自语言推断，实际声学特征仍由音频分支提供。

    提示模板还包含标签字段。论文 Listing C.1 明确测试样本的标签为 None；官方提示的生成代码进一步规定：只有训练集提供标签，验证集和测试集均设为 None。教师模型由此使用了训练期的额外解释信息，学生模型自身始终只接收三模态输入。

    (3) 将长提示压缩为与语言同长的表示。

    论文将提示编码概括为：

    SP=EP(XP;θEP)∈RTL×d.S_P=E_P(X_P;\theta_{E_P})\in\mathbb R^{T_L\times d}.SP​=EP​(XP​;θEP​​)∈RTL​×d.

    EPE_PEP​ 包括预训练 BERT 和两层 Transformer。按实现展开，先把提示的 BERT 表示投影到 64 维，再在前面加入 50 个可学习 token：

    ZP=BERT⁡(XP)WP+bP,SP=Trm⁡P([CP;ZP]+PP)1:TL.Z_P=\operatorname{BERT}(X_P)W_P+b_P,\qquad S_P=\operatorname{Trm}_P([C_P;Z_P]+P_P)_{1:T_L}.ZP​=BERT(XP​)WP​+bP​,SP​=TrmP​([CP​;ZP​]+PP​)1:TL​​.

    CP∈RTL×dC_P\in\mathbb R^{T_L\times d}CP​∈RTL​×d 是可学习的提示汇总 token，PPP_PPP​ 是位置嵌入，[ ; ][\,;\,][;] 表示沿序列维拼接。Transformer 让这些汇总位置读取长提示，最终只保留前 TLT_LTL​ 个输出。这样，提示查询与语言查询都具有 TLT_LTL​ 个位置，可以生成同形的注意力分数图。

    3.3 条件跨模态对齐#

    3.3.1 学生模型的跨模态对齐#

    教师模型也会先计算语言与音视频之间的基础匹配分数，但在归一化之前还会加入提示调制。两者采用相同类型的基础计算，各自学习独立的参数。

    学生有 A→LA\to LA→L 和 V→LV\to LV→L 两条分支，分别从音频和视觉中读取信息，形成以语言位置为索引的表示。下面用 m→Lm\to Lm→L 统一表示其中一条分支，m∈{A,V}m\in\{A,V\}m∈{A,V}，并先解释一层、一个注意力头的计算。上标 SSS 表示学生模型，下一节的上标 TTT 表示教师模型；矩阵转置用 ⊤\top⊤ 表示。

    (1) 语言提供查询，音频或视觉提供可读取的内容。

    设学生的语言表示为 SLS∈RTL×dS_L^S\in\mathbb R^{T_L\times d}SLS​∈RTL​×d，源模态表示为 SmS∈RTm×dS_m^S\in\mathbb R^{T_m\times d}SmS​∈RTm​×d。对齐模块第一层的输入来自模态嵌入。通过三个投影得到：

    QLS=SLSWQS,KmS=SmSWKS,VmS=SmSWVS.Q_L^S=S_L^SW_Q^S,\qquad K_m^S=S_m^SW_K^S,\qquad V_m^S=S_m^SW_V^S.QLS​=SLS​WQS​,KmS​=SmS​WKS​,VmS​=SmS​WVS​.

    WQS,WKS,WVS∈Rd×dkW_Q^S,W_K^S,W_V^S\in\mathbb R^{d\times d_k}WQS​,WKS​,WVS​∈Rd×dk​ 是这一分支中可学习的投影矩阵，dkd_kdk​ 为单头维数。因此 QLSQ_L^SQLS​ 的形状为 TL×dkT_L\times d_kTL​×dk​，KmS,VmSK_m^S,V_m^SKmS​,VmS​ 的形状为 Tm×dkT_m\times d_kTm​×dk​。

    Query 表示每个语言位置需要寻找什么信息；Key 用于判断各音频或视觉位置与查询是否匹配；Value 则是随后真正参与聚合的特征内容。Key 和 Value 来自同一源序列，但使用不同投影。这里 m→Lm\to Lm→L 的方向表示把源模态的信息读到语言位置上，所以 Query 来自语言，Key/Value 来自音频或视觉。

    (2) 为每个语言位置计算它与全部源位置的匹配分数。

    学生的普通跨模态分数为：

    WL,mS=QLS(KmS)⊤dk∈RTL×Tm,WL,mS[i,j]=∑r=1dkQLS[i,r]KmS[j,r]dk.W_{L,m}^S=\frac{Q_L^S(K_m^S)^\top}{\sqrt{d_k}} \in\mathbb R^{T_L\times T_m}, \qquad W_{L,m}^S[i,j] =\frac{\sum_{r=1}^{d_k}Q_L^S[i,r]K_m^S[j,r]}{\sqrt{d_k}}.WL,mS​=dk​​QLS​(KmS​)⊤​∈RTL​×Tm​,WL,mS​[i,j]=dk​​∑r=1dk​​QLS​[i,r]KmS​[j,r]​.

    iii 索引语言位置，jjj 索引源模态位置。矩阵的第 iii 行描述同一个语言位置与全部音频或视觉位置的匹配情况；其中一个分数越大，表示这对位置在当前头学到的特征空间中越匹配。除以 dk\sqrt{d_k}dk​​ 用于控制点积尺度，缓解 softmax 过于尖锐的问题。

    此时 WL,mSW_{L,m}^SWL,mS​ 仍是未归一化的匹配分数矩阵，可以包含负值，尚不是最终读取权重。这里的 WL,mSW_{L,m}^SWL,mS​ 由当前输入动态计算，与上一式中可学习的投影参数 WQS,WKS,WVSW_Q^S,W_K^S,W_V^SWQS​,WKS​,WVS​ 含义不同。

    (3) 学生直接归一化分数，并按所得权重读取源模态。

    学生不接收提示，因此直接对每一行的 TmT_mTm​ 个分数做 softmax：

    AmS=softmax⁡j(WL,mS),AmS[i,j]=exp⁡(WL,mS[i,j])∑u=1Tmexp⁡(WL,mS[i,u]).A_m^S=\operatorname{softmax}_{j}(W_{L,m}^S),\qquad A_m^S[i,j]=\frac{\exp(W_{L,m}^S[i,j])} {\sum_{u=1}^{T_m}\exp(W_{L,m}^S[i,u])}.AmS​=softmaxj​(WL,mS​),AmS​[i,j]=∑u=1Tm​​exp(WL,mS​[i,u])exp(WL,mS​[i,j])​.

    AmS[i,j]A_m^S[i,j]AmS​[i,j] 表示第 iii 个语言位置读取第 jjj 个源位置的权重。softmax 沿源模态位置归一化，所以每一行权重之和为 1。随后用这些权重聚合 Value：

    OmS=AmSVmS∈RTL×dk,OmS[i,:]=∑j=1TmAmS[i,j]VmS[j,:].O_m^S=A_m^SV_m^S\in\mathbb R^{T_L\times d_k}, \qquad O_m^S[i,:]=\sum_{j=1}^{T_m}A_m^S[i,j]V_m^S[j,:].OmS​=AmS​VmS​∈RTL​×dk​,OmS​[i,:]=j=1∑Tm​​AmS​[i,j]VmS​[j,:].

    3.3.2 条件跨模态注意力#

    教师模型还从提示构造 Query。按论文：

    QP=SPWQP,Δm=QPKm⊤dk∈RTL×Tm.Q_P=S_PW_{QP},\qquad \Delta_m=\frac{Q_PK_m^\top}{\sqrt{d_k}} \in\mathbb R^{T_L\times T_m}.QP​=SP​WQP​,Δm​=dk​​QP​Km⊤​​∈RTL​×Tm​.

    Δm\Delta_mΔm​ 表示提示与各源位置的匹配分数，与普通分数 WL,mTW_{L,m}^TWL,mT​ 形状相同。将两者逐元素相乘，再做 softmax：

    Zm=WL,mT⊙Δm,AmT=softmax⁡j(Zm).Z_m=W_{L,m}^T\odot\Delta_m,\qquad A_m^T=\operatorname{softmax}_{j}(Z_m).Zm​=WL,mT​⊙Δm​,AmT​=softmaxj​(Zm​).

    ⊙\odot⊙ 是 Hadamard 乘积，即 Zm[i,j]=WL,mT[i,j]Δm[i,j]Z_m[i,j]=W_{L,m}^T[i,j]\Delta_m[i,j]Zm​[i,j]=WL,mT​[i,j]Δm​[i,j]。用 AmTA_m^TAmT​ 表示原文的 WconW_{\mathrm{con}}Wcon​，以区分未归一化分数与注意力权重。

    提示会影响训练方向。由链式法则可得：

    ∂L∂Wij=∂L∂ZijΔij,∂L∂Δij=∂L∂ZijWij.\frac{\partial\mathcal L}{\partial W_{ij}} =\frac{\partial\mathcal L}{\partial Z_{ij}}\Delta_{ij}, \qquad \frac{\partial\mathcal L}{\partial\Delta_{ij}} =\frac{\partial\mathcal L}{\partial Z_{ij}}W_{ij}.∂Wij​∂L​=∂Zij​∂L​Δij​,∂Δij​∂L​=∂Zij​∂L​Wij​.

    因此，提示既改变前向读取，也改变普通匹配分支收到的梯度。这解释了提示质量为什么会影响教师学习。

    3.4 多模态融合与情感预测#

    完成两条对齐路径后，模型将 HA→LH_{A\to L}HA→L​、HV→LH_{V\to L}HV→L​ 与一个可学习的回归 token c∈R1×dc\in\mathbb R^{1\times d}c∈R1×d 拼接：

    F=Trm⁡F([c;HA→L;HV→L]),Hfusion=F1,:.F=\operatorname{Trm}_F([c;H_{A\to L};H_{V\to L}]), \qquad H_{\mathrm{fusion}}=F_{1,:}.F=TrmF​([c;HA→L​;HV→L​]),Hfusion​=F1,:​.

    融合 Transformer 通过自注意力让两个分支进一步交换信息，并把用于预测的内容汇总。这样，跨模态对齐解决“分别从音频和视觉中读取什么”，最终融合解决“如何综合两个分支的证据”。

    使用线性层输出一个连续分数：

    y^=wr⊤hfusion+br,hfusion∈Rd.\hat y=w_r^\top h_{\mathrm{fusion}}+b_r, \qquad h_{\mathrm{fusion}}\in\mathbb R^d.y^​=wr⊤​hfusion​+br​,hfusion​∈Rd.

    hfusionh_{\mathrm{fusion}}hfusion​ 是单个汇总 token 的向量形式，wr,brw_r,b_rwr​,br​ 是回归头参数。以上按论文的单 token 表述展开；当前公开代码实际使用 4 个回归 token，将 4×644\times644×64 的输出展平为 256 维后送入线性回归头，因此复现时应以代码中的形状为准。网络以情感回归为训练任务，实验中的分类成绩由评价规则得到。

    3.5 两阶段训练与知识蒸馏#

    (1) 第一阶段：用真实标签训练受提示指导的教师。

    教师接收三模态输入与大模型生成的提示，通过条件对齐和融合得到情感预测。将教师的总目标直接定义为情感回归损失：

    LoverallTeacher=LregrTeacher=1N∑i=1N∣y^iT−yi∣.(9)\mathcal L_{\mathrm{overall}}^{\mathrm{Teacher}} =\mathcal L_{\mathrm{regr}}^{\mathrm{Teacher}} =\frac{1}{N}\sum_{i=1}^{N} \left|\hat y_i^T-y_i\right|. \tag{9}LoverallTeacher​=LregrTeacher​=N1​i=1∑N​​y^​iT​−yi​​.(9)

    NNN 是训练样本数，yiy_iyi​ 是第 iii 个样本的真实情感标签，y^iT\hat y_i^Ty^​iT​ 是教师对该样本的预测。每个绝对值衡量一次预测与真实分数之间的距离，对样本取平均后得到 L1 回归损失。

    提示参与教师的前向计算，帮助它分配对音视频信息的注意力；最终仍由真实情感标签判断预测是否准确。这个阶段优化教师模型，使它先学会在提示指导下完成任务。

    (2) 第二阶段：冻结教师，联合优化学生的三类目标。

    教师训练完成后固定参数。学生只接收三模态输入，教师则继续接收三模态输入与提示，为学生提供注意力和融合表示目标。为区分前文的未归一化分数 WL,mW_{L,m}WL,m​ 与归一化注意力 AmA_mAm​，下面使用 AAA 改写原文注意力损失的记号，并以 MAE⁡(U,V)\operatorname{MAE}(U,V)MAE(U,V) 表示两个同形张量逐元素绝对差的均值。

    注意力迁移损失：学习教师如何读取跨模态信息。 将原文式 (10) 按两条对齐分支展开为：

    LattnStudent=1N∑i=1N∑m∈{A,V}MAE⁡ ⁣(AmS,i,AmT,i).(10)\mathcal L_{\mathrm{attn}}^{\mathrm{Student}} =\frac{1}{N}\sum_{i=1}^{N}\sum_{m\in\{A,V\}} \operatorname{MAE}\!\left(A_m^{S,i},A_m^{T,i}\right). \tag{10}LattnStudent​=N1​i=1∑N​m∈{A,V}∑​MAE(AmS,i​,AmT,i​).(10)

    AmS,iA_m^{S,i}AmS,i​ 是学生对齐模块最后一层对第 iii 个样本产生的注意力图；AmT,iA_m^{T,i}AmT,i​ 是论文描述的教师条件注意力图，即原文的 WconiW_{\mathrm{con}}^iWconi​。均值包含各注意力头及语言、源模态位置。两者之差约束学生对源模态各位置的关注方式，使学生即使没有提示，也能学习教师在提示帮助下形成的读取关系。

    实现差异： 当前公开的 core/losses.py 实际读取教师的 h_la_attn 与 h_lv_attn；models/vit.py 将这两个字段保存为提示调制前的 softmax 注意力，调制后的权重另存于 modulate_attn。此外，代码的提示匹配使用 Value 投影，而上述论文公式使用 Key 投影。这些是公开实现与论文表述的差别；理解论文时沿用上式，复现时需核对具体代码版本。

    融合表示匹配损失：学习教师如何汇总多模态证据。 统一学生、教师上标后，原文式 (11) 写为：

    LfusionStudent=1N∑i=1NMAE⁡ ⁣(HfusionS,i,HfusionT,i).(11)\mathcal L_{\mathrm{fusion}}^{\mathrm{Student}} =\frac{1}{N}\sum_{i=1}^{N} \operatorname{MAE}\!\left(H_{\mathrm{fusion}}^{S,i}, H_{\mathrm{fusion}}^{T,i}\right). \tag{11}LfusionStudent​=N1​i=1∑N​MAE(HfusionS,i​,HfusionT,i​).(11)

    HfusionS,iH_{\mathrm{fusion}}^{S,i}HfusionS,i​ 是学生对第 iii 个样本得到的融合表示，HfusionT,iH_{\mathrm{fusion}}^{T,i}HfusionT,i​ 是教师的对应表示。两者都位于多模态融合之后、最终回归预测之前，公开实现比较 4 个回归 token 的输出。注意力迁移约束“从哪些位置读取信息”，融合匹配则进一步约束“综合这些信息后形成怎样的整体表示”。

    情感预测损失：直接学习真实标签。 原文式 (12) 为：

    LregrStudent=1N∑i=1N∣y^iS−yi∣.(12)\mathcal L_{\mathrm{regr}}^{\mathrm{Student}} =\frac{1}{N}\sum_{i=1}^{N} \left|\hat y_i^S-y_i\right|. \tag{12}LregrStudent​=N1​i=1∑N​​y^​iS​−yi​​.(12)

    y^iS\hat y_i^Sy^​iS​ 表示学生对第 iii 个样本的情感预测，yiy_iyi​ 仍是真实标签。这个目标与教师的回归损失采用相同形式，使学生在学习教师内部关系与表示的同时，直接优化最终任务误差。

    三种目标的分工可以总结为：

    学习目标监督来源希望学生学到什么
    注意力迁移 LattnStudent\mathcal L_{\mathrm{attn}}^{\mathrm{Student}}LattnStudent​教师最后一层的条件注意力图每个语言位置应如何分配对音视频的读取权重
    融合匹配 LfusionStudent\mathcal L_{\mathrm{fusion}}^{\mathrm{Student}}LfusionStudent​教师的融合表示汇总多模态证据后应形成怎样的表示
    情感回归 LregrStudent\mathcal L_{\mathrm{regr}}^{\mathrm{Student}}LregrStudent​真实情感标签最终情感分数应接近多少

    将三种目标加权组合，得到学生的总损失：

    LoverallStudent=LregrStudent+αLattnStudent+βLfusionStudent.(13)\mathcal L_{\mathrm{overall}}^{\mathrm{Student}} =\mathcal L_{\mathrm{regr}}^{\mathrm{Student}} +\alpha\mathcal L_{\mathrm{attn}}^{\mathrm{Student}} +\beta\mathcal L_{\mathrm{fusion}}^{\mathrm{Student}}. \tag{13}LoverallStudent​=LregrStudent​+αLattnStudent​+βLfusionStudent​.(13)

    回归损失的系数为 1，α\alphaα 控制注意力迁移的权重，β\betaβ 控制融合表示匹配的权重。论文在 SIMS 上取 (α,β)=(60,8)(\alpha,\beta)=(60,8)(α,β)=(60,8)，在 MOSI 上取 (100,4)(100,4)(100,4)；附录给出的 MOSEI 配置同样为 (100,4)(100,4)(100,4)。这些系数用于平衡不同目标对学生训练的影响，具体效果通过损失消融与权重实验比较。因此，学生的训练监督包含真实标签和教师的两类内部信息。

    (3) 训练结束后，仅用学生进行预测。

    完整流程是先生成并缓存提示、训练教师，再冻结教师训练学生。第二阶段的梯度只更新学生参数，教师的注意力和融合表示作为固定的监督目标；教师仍会随样本输入产生不同的输出。

    部署时保留学生的模态嵌入、普通跨模态对齐、多模态融合与回归路径，即可由三模态输入独立预测。提示与教师的指导通过训练影响学生参数，推理时无需再次调用它们。

    4. 具体实验#

    4.1 实验设置#

    • 任务与输入：利用语言、视觉和声学信息进行片段级情感回归，并报告情感二分类结果。默认提示来自 GPT-4o-mini，三帧视频加转录文本，训练前生成一次并缓存。
    • 数据划分：采用本论文给出的训练、验证、测试划分，统计如下。
    数据集训练验证测试标签范围数据来源
    SIMS1,368456457[−1,1][-1,1][−1,1]中文影视、综艺片段
    MOSI1,284229686[−3,3][-3,3][−3,3]英文网络视频
    MOSEI16,3261,8714,659[−3,3][-3,3][−3,3]更大规模英文网络视频
    • 训练：教师和学生均采用 L1 回归损失与 AdamW，batch size 为 64，训练 200 个 epoch，使用 warm-up 和余弦退火，在 A40 上运行。主要结果按 1111–1115 五个随机种子统计。统一特征维度为 64。
    • 指标：Acc-2 与 F1 评价情感方向，MAE 评价连续分数误差，Corr 评价预测与标签的相关性。MAE 越小越好，其余越大越好。MOSI/MOSEI 的斜线左、右分别为“负面/非负面”和“去除零分后的负面/正面”两种口径；分类变化以下均用百分点表示。
    • 模型选择：主实验的任务模型分别按验证集 Acc-2 和 MAE 选择用于分类、回归的模型检查点；直接预测的大模型也采用分别面向分类、回归的提示。

    4.3 关键实验结果#

    4.3.1 多模态整体性能#

    SIMS：学生相对 ALMT 同时改善分类和回归，教师仍有更高的分类表现。

    MMSLF-Student 的 F1 为 81.85%，比 ALMT 的 80.17% 提高 1.68 个百分点；MAE 从 0.421 降至 0.382，Corr 从 0.583 提高到 0.662。教师 F1 为 84.06%，学生保留了一部分教师收益，但仍有 2.21 个百分点的差距。

    与全部方法比较，DeepMLF 的 MAE 为 0.362，Gemini 的 F1 为 84.69%，均有优于学生的指标。因此，该结果体现学生在较小模型规模下的竞争力。

    MOSI：学生分类略有改善，情感强度预测没有同步超过 ALMT。

    相对 ALMT，学生 F1 从 83.00 / 85.19 提高到 83.68 / 85.50，分别增加 0.68 / 0.31 个百分点；但 MAE 从 0.713 增至 0.746，Corr 从 0.795 降至 0.775。教师的 F1 进一步提高到 85.15 / 86.69，仍低于表中的 GPT-4o-mini 和 Gemini。

    MOSEI：学生保持有竞争力的分类表现，回归优势较有限。

    学生 F1 为 84.20 / 84.74，比 ALMT 提高 0.10 / 0.49 个百分点；MAE 为 0.548，略高于 ALMT 的 0.542，也高于 DeepMLF 的 0.510。教师达到 85.55 / 86.71 的 F1，表明提示指导下的教师在较大数据集上仍能获得较强分类结果，但这些收益没有被学生完全保留。

    三个数据集共同表明：MMSLF 的主要价值在于让独立运行的小模型利用大模型指导。收益最明显的设置是 SIMS；在 MOSI、MOSEI 上，应同时结合分类、回归和效率评价其效果。

    4.3.3 定性分析#

    训练过程。 展示 SIMS、MOSI 上学生的回归、注意力迁移和融合匹配损失，曲线对应五次运行的平均趋势。

    整体损失随训练下降，说明学生能够同时学习任务预测与教师内部表示。其中注意力迁移的波动较明显：学生没有提示输入，却要依据三模态信息接近受提示指导的教师关系，这一目标较难完全匹配。

    注意力可视化。 将教师有提示与无提示时的注意力相减，展示同一样本的信息读取如何变化。

    蓝色区域表示加入提示后注意力增大，橙色表示减小。结合“眼神游移或向下看可能表达失落”的提示，模型对部分眼部、嘴部动作更明显的帧增加关注，展示了提示影响跨模态读取的具体方式。

    6. 局限性与启示#

    (1) 局限

    提示质量和监督来源尚未被完全分离。训练提示包含标签条件，大模型可能利用已有答案组织解释；现有消融验证了提示整体有效，但尚不足以确定通用知识、视频线索与标签条件表述各贡献多少。默认只采样三帧、没有直接音频输入，也可能遗漏细微动作和语音情绪。

    知识迁移存在信息与容量约束。教师能使用自然语言提示，学生只能依据自身输入特征恢复关系；部分大模型识别到的细节可能没有完整保留在学生特征中。

    部署效率以额外训练成本为前提。学生运行时可移除大模型与教师，但离线提示生成、教师训练和蒸馏仍需资源；较长序列使小参数模型也可能具有较高计算量。

    (2) 启示

    MMSLF 值得掌握的设计是：先把大模型的语言解释转化为任务网络的结构化关系，再将关系和融合表示迁移给学生。 条件注意力连接了自然语言提示与跨模态读取，双重蒸馏连接了受提示指导的教师与无提示学生，使训练期额外信息能够服务独立部署。
